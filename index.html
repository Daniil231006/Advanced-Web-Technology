What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure content on websites.

HTML is not a programming language. It is a markup language that tells the web browser how different parts of a webpage are organized. HTML can be used to create headings, paragraphs, links, images, lists, tables, forms, videos and many other elements.

How Does HTML Work?

HTML uses special words called tags. Tags are written inside angle brackets. For example, the <p> tag is used to create a paragraph. 

<p>This is a paragraph.</p>

The first tag is called the opening tag and the second tag is called the closing tag. The content is placed between them.

HTML Elements

An HTML element normally consists of an opening tag, content and a closing tag. 

<h1>My Website</h1>

In this example, <h1> is the opening tag, "My Website" is the content, and </h1> is the closing tag.

HTML Attributes

Attributes provide additional information about an HTML element. They are written inside the opening tag.

For example, the href attribute tells the browser where a link should go. 

<a href="https://example.com">Visit Example</a>

Another common attribute is src, which is used to specify the source of an image. 

<img src="images/photo.jpg" alt="A photo">

Basic HTML Document Structure

Every HTML document normally has a basic structure. It contains the <html>, <head> and <body> elements. 

<!DOCTYPE html>

<html>

    <head>
        <title>My Website</title>
    </head>

    <body>
        <h1>Hello World</h1>
        <p>Welcome to my website.</p>
    </body>

</html>

Common HTML Tags

  • <h1> - Main heading
  • <h2> - Second-level heading
  • <p> - Paragraph
  • <a> - Link
  • <img> - Image
  • <ul> - Unordered list
  • <ol> - Ordered list
  • <table> - Table
  • <form> - Form
  • <video> - Video
  • <audio> - Audio

Why is HTML Important?

HTML is one of the main technologies used to build websites. It provides the structure of a webpage, while CSS is used to control its appearance and JavaScript can be used to add interactive features.

Learning HTML is an important first step in web development because it helps us understand how webpages are structured and how browsers display information.
