HTML Metadata

Metadata is information about a webpage that is not normally displayed directly on the page. Metadata is placed inside the <head> element.

Metadata provides information to browsers, search engines and other services about the document.

The Head Element

The <head> element contains information about the HTML document. It can include the title, character encoding, viewport settings, descriptions, stylesheets and other metadata. 

```



```
<meta charset="UTF-8">

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

<title>My Website</title>
```
```

Character Encoding

The <meta charset="UTF-8"> element specifies the character encoding of the document. UTF-8 supports many languages and special characters. 

```
```

Viewport Metadata

The viewport meta tag helps webpages display correctly on mobile devices. It is especially important for responsive design. 

```
```

Description

The description meta tag provides a short description of the webpage. Search engines may use this information when displaying search results. 

```
```

Keywords

The keywords meta tag can contain words related to the webpage. It is part of the historical use of metadata, although modern search engines generally do not use it as an important ranking factor. 

```
```

Author

The author metadata identifies the creator or author of the document. 

```
```

Link Element

The <link> element is commonly used to connect an external CSS stylesheet to an HTML document. 

```
```

The rel attribute describes the relationship between the current document and the linked resource.

Title Element

The <title> element defines the title of the webpage. It is displayed in the browser tab and is also useful for search engines.

Example of a Complete Head

```



```
<meta charset="UTF-8">

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

<meta name="description"
      content="HTML Review Website">

<meta name="author"
      content="Advanced Web Technology Student">

<title>HTML Review Website</title>

<link rel="stylesheet" href="style.css">
```
```

Important Metadata Elements

  • <title> - Defines the page title.
  • <meta charset> - Defines character encoding.
  • <meta name="viewport"> - Controls mobile display.
  • <meta name="description"> - Describes the page.
  • <meta name="author"> - Identifies the author.
  • <link> - Connects external resources.

Why is Metadata Important?

Metadata helps browsers understand how a webpage should be displayed and provides additional information about the document. Correct metadata also improves accessibility, responsiveness and the general quality of a webpage.
