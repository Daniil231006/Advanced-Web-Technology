Semantic HTML

Semantic HTML uses elements that clearly describe the meaning and purpose of their content. Semantic elements make webpages easier to understand for developers, browsers and assistive technologies.

Why Semantic HTML is Important

Semantic elements improve the structure of a webpage. They can also improve accessibility, search engine optimization and code readability.

Header

The <header> element represents introductory content for a webpage or a section. It commonly contains a title, logo or navigation. 

```




My Website


Welcome to my website.
```

Navigation

The <nav> element represents a section containing navigation links. 

```



Home
About
Contact
```

Main

The <main> element contains the main content of a webpage. There should normally be one main element per page. 

```




Welcome


This is the main content.
```

Section

The <section> element represents a thematic section of content. It usually has a heading. 

```




About HTML


HTML is a markup language.
```

Article

The <article> element represents independent and reusable content, such as a news article, blog post or forum post. 

```




Introduction to HTML


HTML is used to structure webpages.
```

Aside

The <aside> element contains additional information related to the main content. 

```




Related Information


HTML works together with CSS and JavaScript.
```

Footer

The <footer> element represents the footer of a webpage or section. It often contains copyright information, contact information or additional links. 

```




Copyright 2026 My Website
```

Common Semantic Elements

  • <header> - Introductory content.
  • <nav> - Navigation links.
  • <main> - Main page content.
  • <section> - Thematic section.
  • <article> - Independent content.
  • <aside> - Related or additional content.
  • <footer> - Footer information.
  • <figure> - Self-contained media or content.
  • <figcaption> - Caption for a figure.

Semantic vs Non-Semantic Elements

Semantic elements describe their purpose. For example, <article> clearly represents an article. A <div> element does not describe its content and is therefore considered a non-semantic container.
