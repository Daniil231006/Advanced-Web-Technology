HTML Tables

HTML tables are used to organize information into rows and columns. Tables are useful for displaying structured data, such as schedules, prices, statistics and student information.

Basic Table Structure

A table uses the <table> element. Rows are created with <tr>, table headers with <th>, and table data with <td>. 

```



```
<tr>
    <td>Alex</td>
    <td>20</td>
</tr>

Table Head, Body and Footer

Larger tables can be divided into three logical sections: <thead>, <tbody> and <tfoot>. 

```



```
<thead>
    <tr>
        <th>Product</th>
        <th>Price</th>
    </tr>
</thead>

<tbody>
    <tr>
        <td>Keyboard</td>
        <td>$50</td>
    </tr>
</tbody>

<tfoot>
    <tr>
        <td>Total</td>
        <td>$50</td>
    </tr>
</tfoot>

Important Table Tags

  • <table> - Creates a table.
  • <tr> - Creates a table row.
  • <th> - Creates a header cell.
  • <td> - Creates a data cell.
  • <thead> - Defines the table header.
  • <tbody> - Defines the table body.
  • <tfoot> - Defines the table footer.
  • <caption> - Defines the table title.
