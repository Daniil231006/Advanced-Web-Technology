HTML Text Formatting Tags

Learn how HTML is used to organize and format text.

1. Headings

HTML provides six heading levels, from <h1> to <h6>. The <h1> element is the most important heading, while <h6> is the smallest level.

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5
Heading 6

Example

<h1>My Main Heading</h1>
<h2>My Subheading</h2>

2. Paragraphs

The <p> tag is used to create a paragraph. Paragraphs are one of the most common elements in HTML.

This is an example of a paragraph written using HTML.

Example

<p>This is my first paragraph.</p>

3. Bold Text

The <b> tag makes text visually bold. The <strong> tag also makes text bold, but it indicates that the text has strong importance.

This is bold text.

This is important text.

Example

<b>Bold text</b>

<strong>Important text</strong>

4. Italic Text

The <i> tag displays text in italic style. The <em> tag is used to emphasize text.

This is italic text.

This is emphasized text.

Example

<i>Italic text</i>

<em>Emphasized text</em>

5. Underlined Text

The <u> tag is used to display underlined text.

This is underlined text.

Example

<u>Underlined text</u>

6. Highlighted Text

The <mark> tag highlights part of the text.

This is highlighted text.

Example

<mark>Important information</mark>

7. Small Text

The <small> tag displays smaller text.

Normal text and small text.

Example

<small>This is small text.</small>

8. Deleted and Inserted Text

The <del> tag represents deleted text. The <ins> tag represents inserted text.

Old price: $50

New price: $40

Example

<del>$50</del>

<ins>$40</ins>

9. Subscript and Superscript

The <sub> tag creates subscript text. The <sup> tag creates superscript text.

Water: H2O

Mathematics: x2

Example

H<sub>2</sub>O

x<sup>2</sup>

10. Line Break

The <br> tag creates a line break without starting a new paragraph.

First line
Second line
Third line

Example

First line<br>
Second line<br>
Third line

11. Horizontal Line

The <hr> tag creates a horizontal line and is commonly used to separate sections of content.

Example

<hr>

12. Quotes

The <q> tag is used for a short quotation.

My teacher said: Practice makes progress.

Example

<q>Practice makes progress.</q>

The <blockquote> tag is used for a longer quotation.

Learning HTML is an important first step in understanding how websites are created.

Example

<blockquote>
    Learning HTML is an important first step.
</blockquote>
