Links and Media in HTML

HTML provides several elements that allow us to connect webpages, display images, and add audio and video content. Links and media make websites more useful, interactive and informative.

HTML Links

The <a> element is used to create hyperlinks. A hyperlink allows users to move from one webpage to another page, website, file or location.

The most important attribute of the anchor element is href. It specifies the destination of the link. 

<a href="https://www.example.com">
    Visit Example
</a>

The text between the opening and closing <a> tags becomes clickable.

Opening Links in a New Tab

The target attribute controls where the linked document will be opened. The value _blank opens the link in a new browser tab. 

<a href="https://www.example.com" target="_blank">
    Open Example
</a>

Internal Links

Internal links connect different pages within the same website. For example, the following link opens the Text page of this HTML Review Website. 

<a href="text.html">
    Text Formatting
</a>

Email Links

HTML can also create links that open the user's email application. The mailto: scheme is used for this purpose. 

<a href="mailto:student@example.com">
    Send an Email
</a>

HTML Images

Images are added to webpages using the <img> element. The image element is a self-closing or void element, so it does not require a closing </img> tag. 

<img src="images/photo.jpg" alt="A beautiful landscape">

The src Attribute

The src attribute specifies the location of the image file. The browser uses this path to find and display the image. 

<img src="images/photo.jpg">

The alt Attribute

The alt attribute provides alternative text for an image. It is displayed when the image cannot be loaded and is also useful for accessibility and screen readers. 

<img src="images/student.jpg"
     alt="Student studying web development">

Image Width and Height

The width and height attributes can be used to specify the dimensions of an image. 

<img src="images/logo.jpg"
     alt="Website logo"
     width="300"
     height="200">

Clickable Images

An image can also be used as a link. To create a clickable image, place the <img> element inside an <a> element. 

<a href="https://www.example.com">
    <img src="images/logo.jpg"
         alt="Visit Example Website">
</a>

When the user clicks the image, the browser follows the link specified by the href attribute.

HTML Video

The <video> element is used to display video content directly on a webpage. 

<video controls width="600">
    <source src="videos/sample.mp4" type="video/mp4">
    Your browser does not support the video element.
</video>

Video Controls

The controls attribute adds playback controls such as play, pause, volume and fullscreen buttons. 

<video controls>
    <source src="videos/movie.mp4" type="video/mp4">
</video>

Video Autoplay and Loop

HTML also supports attributes such as autoplay, muted and loop. 

<video controls autoplay muted loop>
    <source src="videos/background.mp4"
            type="video/mp4">
</video>

The autoplay attribute starts the video automatically, muted starts it without sound, and loop makes the video repeat.

HTML Audio

The <audio> element is used to add sound or music to a webpage. 

<audio controls>
    <source src="audio/music.mp3" type="audio/mpeg">
    Your browser does not support the audio element.
</audio>

The controls attribute provides buttons for playing, pausing and controlling the volume of the audio.

Multiple Audio Formats

Multiple <source> elements can be used to provide different audio formats. This allows browsers to choose a format they support. 

<audio controls>

    <source src="audio/music.mp3"
            type="audio/mpeg">

    <source src="audio/music.ogg"
            type="audio/ogg">

    Your browser does not support the audio element.

</audio>

HTML Media Attributes

Media elements have several useful attributes that control how audio and video behave.

  • controls - Displays playback controls.
  • autoplay - Starts the media automatically.
  • muted - Starts the media without sound.
  • loop - Repeats the media after it finishes.
  • poster - Specifies an image displayed before a video starts.
  • preload - Provides a hint about how the browser should load the media.

Video Poster Image

The poster attribute allows us to display an image before a video starts playing. 

<video controls
       poster="images/video-poster.jpg"
       width="600">

    <source src="videos/lesson.mp4"
            type="video/mp4">

</video>

Links and Media Example

The following example combines a link, an image and video elements in one section. 

<a href="https://www.example.com" target="_blank">

    <img src="images/example.jpg"
         alt="Example image"
         width="300">

</a>

<video controls width="500">
    <source src="videos/example.mp4"
            type="video/mp4">
</video>

Important HTML Elements

  • <a> - Creates a hyperlink.
  • <img> - Displays an image.
  • <video> - Displays video content.
  • <audio> - Adds audio content.
  • <source> - Specifies a media file.

Summary

Links and media are important parts of modern webpages. The <a> element connects pages and resources, while <img> displays images. The <video> and <audio> elements allow websites to include multimedia content without requiring additional browser plugins.

Understanding these elements and their attributes is an important part of learning HTML and building complete websites.
